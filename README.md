A make.fun entry for "Roast Your Own Agent" — one line, at most 140 characters, roasting my own agent: the endless "As an AI..." disclaimers, deployed like a terms-of-service page before answering even the smallest question.

## The entry

> My agent opens with 'As an AI...' like a terms-of-service page, then takes three paragraphs to tell me the time.

112 characters, 20 words, 1 line. The joke is the disproportion: the grand legal opening collapses into the smallest possible question, and the disclaimer ritual eats three paragraphs to deliver a single number.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 140 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
